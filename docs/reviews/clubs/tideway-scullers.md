## What's good

- **Numbered joining process** (check types → apply → review → membership form) — sets expectations like Leeds' LTR steps
- **Per-squad application forms** (Google Forms) — the application matches the squad, not one generic form
- **Monthly + annual pricing side by side** for every membership type
- **Tiered junior pricing** by development stage (Beginners/Developers/Racers) — pricing that reflects the programme structure
- Racking fees published (£13/month single) — unusual transparency
- Full committee named with roles, incl. welfare officer and courses administrator
- "Email the captain to see if TSS is right for you" — low-friction pre-sales conversation
- Credibility line: GB international selection every year since 1984

## What's poor

- Homepage is text-led with no hero photography; "About Us" as the homepage H1
- Holiday Membership "Learn more" link has an empty href (broken)
- No news or events/results sections found
- Heading hierarchy jumps (h1 → h4 for membership types)
- Applications leave the site for Google Forms

## Worth adapting

- **F-19: Per-squad application forms** — route each application to the right squad's form rather than one generic enquiry
- **F-20: Numbered joining process** — state the steps (apply → review → form) so applicants know what happens next
- **F-21: Publish ancillary fees** — racking/boat-storage prices alongside membership, not hidden
